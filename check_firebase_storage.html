Firebase Storage Bucket URL

เปิด URL นี้ใน Browser:

https://console.cloud.google.com/storage/browser/farm-management-system-fae8c.appspot.com?project=farm-management-system-fae8c

ถ้าเปิดได้ และเห็นรายการไฟล์: ✅ Firebase Storage เปิดแล้ว

ถ้าเปิดแล้วขึ้น Error 404: ❌ Firebase Storage ยังไม่เปิด



ถ้ายังไม่เปิด ให้เปิดที่นี่:

Firebase Console → Storage

หลังจากเปิด Firebase Storage แล้ว:

  1. กลับมาที่ Google Cloud Console
  2. คลิก "Go to a specific path"
  3. ใส่: farm-management-system-fae8c.appspot.com
  4. คลิก "Go"
  5. คลิก Tab "Configuration"
  6. Scroll ลงหา "CORS Configuration"
  7. คลิก "Edit CORS configuration"
  8. Paste JSON: 
    [
  {
    "origin": ["*"],
    "method": ["GET"],
    "responseHeader": ["Content-Type"],
    "maxAgeSeconds": 3600
  }
]
  9. คลิก "Save"
